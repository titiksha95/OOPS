# C# Object-Oriented Programming Concepts

This repository contains simple, beginner-friendly C# programs demonstrating the fundamental and advanced concepts of Object-Oriented Programming (OOP). Each topic is implemented separately so it can be studied, executed, and understood independently.

## About the Project

The purpose of this project is to build a strong understanding of OOP in C# through practical examples. It explains how classes and objects organize application data and behaviour and how encapsulation, inheritance, polymorphism, and abstraction make software reusable, secure, flexible, and maintainable.

## Topics Covered

- Classes and objects
- Encapsulation
- Default and parameterized
- Single, multilevel, hierarchical, and interface-based multiple inheritance
- Compile-time polymorphism through method overloading
- Runtime polymorphism through method overriding
- Abstraction using abstract classes and interfaces
- Properties and access modifiers

## Four Pillars of OOP

| Pillar | Purpose |
|---|---|
| Encapsulation | Protects data and controls how it is accessed or modified |
| Inheritance | Reuses and extends the functionality of existing classes |
| Polymorphism | Allows the same operation to produce different behaviour |
| Abstraction | Exposes essential functionality while hiding implementation details |

## How to Run

1. Clone or download this repository.
2. Open the solution in Visual Studio.
3. Select the example you want to practise.
4. Ensure only one `Main()` method is used as the startup entry point.
5. Run the application with `Ctrl + F5`.

Alternatively, run a project from the terminal:

```bash
dotnet run
```

## Learning Outcomes

After completing these examples, you should be able to:

- Create classes and objects in C#.
- protect data using encapsulation and access modifiers.
- Reuse code through inheritance.
- Apply compile-time and runtime polymorphism.
- Design contracts using interfaces.
- Understand abstract classes and abstraction.
- Model relationships between objects.
- Write loosely coupled code using dependency injection.
